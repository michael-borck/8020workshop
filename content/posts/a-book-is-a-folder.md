title: "A book is a folder of text files"
date: 2026-09-12

Back in March I wrote about having seven books out in the world. The shelf has kept growing since then, and people keep asking the wrong question about it. They ask how I find the time to publish. Publishing is the fast part. Writing is slow, same as it ever was.

The trick, if it counts as one, is that each book is a folder of plain text files. Chapters are text. The contents page is text. One command turns the folder into a website, a PDF, or an ebook file. I write in the same editor I use for notes, on the same machine, with no special software between me and the words.

This is the plain text series from earlier this year, played out at book scale. The bet was that text files outlive apps. For a book that bet matters more, not less. A book should still open in twenty years. A folder of text will. A project file from a publishing app that folded in 2019 will not.

Plain text also makes revision cheap. Moving a chapter is renaming files. Finding every place I used a term wrong is one search. The whole book fits in a backup so small it feels like a rounding error.

I am not going to list the catalogue here. This site is the wrong room for a bookshop, and the books have their own home. I just like that the biggest things I make are built from the smallest, dullest files on the computer: boring files, interesting books.
