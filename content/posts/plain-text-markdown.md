*Part of the [Plain Text Is Forever](/posts/plain-text-is-forever/) series.*

Raw `.txt` works for quick notes and task lists. When you need headings, links, code blocks or emphasis, Markdown gives you all of that without leaving the keyboard. It is readable as-is, no rendering required, and it converts to almost anything: HTML, DOCX, PDF, slides.

Write once, render everywhere.

## Just enough syntax

The syntax takes ten minutes to learn and is powerful enough to write whole books. A `#` for a heading. `**` for bold. `-` for a list. `[text](url)` for a link. That covers about 90% of what most people need most of the time.

Because it is text with conventions, there is no binary format to corrupt, no version incompatibility to debug and no "please upgrade to access your files" message.

## Readable without rendering

This is what separates Markdown from other markup languages. An HTML file without a browser is a mess of angle brackets. A LaTeX file without a compiler is barely readable. A Markdown file is still a clear document without anything.

The source is the document. Rendering just makes it prettier.

## The conversion pipeline

Markdown's real power shows up when you need output in several formats. The same `.md` file can become:

- A blog post (Hugo, Jekyll, Astro)
- A PDF (Pandoc, Quarto)
- A slide deck (Marp, reveal.js)
- A Word document (Pandoc)
- An email (most Markdown editors)

One source file, many outputs. No copy-pasting between formats and no wondering which version is current.

## Where it fits

Plain text is the foundation. Markdown is plain text with enough structure for longer writing. You don't need Markdown for a shopping list, but the moment you want sections, links or code it earns its keep without adding much complexity.

Minimal syntax, wide reach.
