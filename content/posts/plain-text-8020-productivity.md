You don't need a complex system to be organised. You need a text editor you enjoy using, a folder structure that makes sense to you, and the discipline to write things down.

## The three-file system

A `todo.txt` for tasks. A folder of Markdown files for notes and drafts. A work journal you open every morning. These three habits, backed by plain text, will outperform an app that tries to be everything for everyone.

Skip the project boards, kanban views and priority matrices. You need a list you look at, a place to think and a daily habit of writing down what matters.

## Why simplicity wins

The people who get the most done aren't optimising their tool stack. They write things down and do them. Plain text gets out of the way and lets that happen.

Every feature a productivity app adds is a decision it asks you to make. Tags or folders? Priority levels or due dates? Board view or list view? Each decision feels small, but they add up to a system that demands maintenance. You end up spending time *on* the system instead of *in* it.

A text file asks one question: what do you want to write?

## No setup

Open your editor. Create a file. Start typing.

There is no signup, no onboarding, no tutorial video, and no "getting started" guide that takes longer to read than the work itself.

## Start today

If you already use Markdown in any flavour, whether Obsidian, Quarto, Logseq or a plain text editor, you are already in. If you don't, create a folder called `notes`, open a file called `today.md` and start writing.

The format will outlast every app on your phone.
